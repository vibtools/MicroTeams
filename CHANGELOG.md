# Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - 2026-09-17
### Added
- **System Backup & Disaster Recovery Engine**:
  - One-click Neon PostgreSQL full database snapshots & table dumps.
  - Cloudflare R2 file catalog and asset manifest backups.
  - Interactive JSON upload & safe schema synchronization restore engine with real-time progress indicators.
- **Admin Panel Refinement**:
  - Cleaned up redundant subtitles and helper descriptions across all panels and modals for a compact, high-density interface.

## [1.1.0] - 2026-08-15
### Added
- Worker job queues and microjob submission approval pipelines.
- Excel data ingestion and bulk pipeline management.
- Cloudflare R2 file storage integration and S3 API token verifier.

## [1.0.0] - 2026-07-01
### Initial Release
- Core React + Express architecture.
- Leader and worker authentication dashboard.
