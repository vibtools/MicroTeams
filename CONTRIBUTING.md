# Contributing to Team Dark Devil Platform

Thank you for your interest in contributing to the Team Dark Devil platform! Please follow these guidelines to ensure smooth collaboration.

## Code of Conduct
By participating, you agree to abide by our core values of respect, collaboration, and secure coding practices.

## How to Contribute

1. **Fork the Repository**
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **Commit Your Changes**:
   ```bash
   git commit -m "Add amazing feature"
   ```
4. **Push to the Branch**:
   ```bash
   git push origin feature/amazing-feature
   ```
5. **Open a Pull Request**

## Development Guidelines
- Maintain the compact dark theme styling.
- Ensure TypeScript type safety (`npm run lint`).
- Test all database queries and backup/restore workflows locally.
